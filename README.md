# Инструктор — Brake It, Anton

Играбельный прототип: ученик Антон сам газует и сам рулит. Игрок только тормозит.

Это не автосимулятор и не тренажёр ПДД. Победа — доехать, не разбив машину и груз и не доведя Антона до истерики.

## Запуск

Нужен любой статический сервер. Сборка не нужна.

```bash
node tools/serve.js
```

Открыть [http://127.0.0.1:4173](http://127.0.0.1:4173). Альтернатива: `python3 -m http.server 4173` из корня репозитория.

`file://` не подходит: браузер блокирует ES-модули.

Телефон держать горизонтально, 16:9. В портрете игра просит перевернуть экран и не строит вертикальную вёрстку.

Проверки для разработки (не нужны, чтобы просто играть):

```bash
npm install
npm test
npm run check
npm run lint
npx playwright install chromium
npm run test:e2e
```

`?debug=1` показывает скорость и терпение. `?e2e=1` ускоряет симуляцию для автотестов. В меню этих режимов нет.

## Управление

- Красная педаль, удержание пальцем или Space. Короткое нажатие только притормаживает, длинное останавливает. Палец можно увести с кнопки — тормоз не отпустится, пока палец на экране.
- Esc или значок паузы. Потеря фокуса и сворачивание тоже ставят паузу и сбрасывают педаль.
- На экране результата: «Ещё раз» и «Дальше». R повторяет попытку.

## Что есть в прототипе

- Альбомный холст 1600×900, letterbox, `touch-action: none`.
- Четыре поездки по старому двору и бесконечный «Последний урок» после первого успешного урока.
- Опасности: одноглазый пешеход, прямоугольная собака, бак, выезжающая машина, стоящая машина, яма. Часть из них Антон объезжает сам — тормоз в этот момент его срывает.
- Груз только один на поездку: урок 3 торт, урок 4 аквариум и мокрый участок.
- Терпение 0–100, корпус, комфорт/груз, звёзды, значок «Почти не понадобился».
- Пауза, настройки звука и тряски, сохранение `localStorage` схемы v1.
- Синтезированный Web Audio без скачанных сэмплов. Жест игрока нужен, чтобы звук вообще включился.

## Чего нет

Других учеников, районов, тёщи, экзамена, магазина, рекламы, аккаунтов и сети. Бесконечный режим не продаёт ремонт: в конце комическая смета.

## Отличия от черновика ТЗ

Полный текст задания лежит в `docs/TZ_Instructor.md` (и рядом арт-доки).

- Движок — HTML5 Canvas и vanilla JS, не Godot. Так просили для этого прототипа.
- Цифры терпения взяты из брифа на прототип, а не из раннего черновика §5.3. Старт 15, жёсткое торможение на пустой дороге +7.2/с при замедлении > 4.8 и педали > 0.35, после 2.2 с удержания ещё +0.35/с, короткое отпускание до 0.65 с снимает 0.4, спокойная езда быстрее 5 м/с дольше 2.5 с остывает на 0.5/с. Торможение перед настоящей опасностью почти не злит. Разовый +10 — только если вклад педали превысил 8.5 м/с².
- Пока педаль нажата, Антон сбрасывает догоняющий газ. Иначе его собственный газ съедает тормоз и короткое нажатие не отличается от длинного.
- `a(v)` при полном нажатии равен 8.5 м/с² на 100 км/ч и растёт со скоростью. Это член тормоза в `v += (throttle - drag·v - brake·a(v))·dt`, а не вся результирующая ускорения.
- В сцену вошли и опасности из ТЗ (пешеход, бак, выезжающая машина, собака), и близкие из брифа (стоящая машина, яма).
- Звёзды: с грузом 40% корпус + 35% груз + 25% нервы, без груза 50/20/30. Нервы = 100 − терпение. Пороги 80 / 60 / 35. Провал даёт 0 звёзд. Значок не выдаётся за пустую поездку без ни одного осмысленного решения.
- На старых макетах спокойный Антон нарисован злым, а шкала красная. В игре при терпении 0–39 лицо спокойное, подпись «Терпит», указатель в зелёной трети.
- Звук оригинальный и синтезированный. Кандидаты Kenney в проект не скачивались.
- Телефон руками не проверялся. Это прототип, не релизная сборка.
