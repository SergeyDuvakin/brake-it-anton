## 0. Снос машины («Антон уснул / засмотрелся»)

### 0.1 Как команда это видит
- **Геймдизайн:** снос — это видимая причина тыкать в Антона прямо сейчас, а не «где-то впереди будет яма». Нужно честное время на реакцию: от начала сноса до первого возможного удара не меньше 3 с на круизе 10 м/с. Тормоз сносить не мешает, но, сбросив скорость, игрок выигрывает время. Это честная физика: боковое смещение пропорционально скорости, и это оставляет тормозу смысл, не делая его рулём.
- **Пиксель-арт:** снос читается по смещению машины, по голове Антона, которая клонится в сторону сноса, и по лёгкому повороту носа машины (кадры `learner-yaw-l/r`, дефолт реализации; якорь +1 px, см. §A.2).
- **Программист:** нужен общий для симуляции и рендера модуль придорожных объектов, чтобы «что видно — то и бьётся». Также нужно новое состояние бокового движения и расширенный кламп по x.
- **QA:** детерминизм по seed, минимальное время до удара, возврат в полосу, отсутствие ложных аварий в обычной езде (центр ≤ 2,4 м — к предметам не прикоснуться).
- **Мобайл:** снос виден на узком экране, так как мир занимает ~470 CSS px по ширине. Прятать нечего.

### 0.2 Правила и числа (`CFG.drift`, новый блок в `js/config.js`)
```
drift: {
  startDelay: 0.8,        // с после входа в phone/drowsy/asleep — Антон сначала держит руль
  maxLat: { phone: 0.32, drowsy: 0.18, asleep: 0.40, grope: 0.45 }, // м/с при v ≥ refSpeed
  rampFrom: 0.25, rampTime: 3.0, // разгон бокового движения: k = min(1, 0.25 + t/3)
  refSpeed: 9,            // м/с; множитель скорости = clamp(v/9, 0, 1.2); стоим — не сносит
  holdMin: 1.4, holdMax: 2.8, flipChance: 0.4, // смена направления: держит 1,4–2,8 с, потом 40% разворот
  maxOffset: 4.18,        // |x| центра: 5,03 (стена домов) − 0,85
  curbX: 2.4,             // корпус съезжает с асфальта (бордюр)
  recoverDelay: 0.35, recoverRate: 1.4, // возврат в полосу после пробуждения
  softHit: 1.2,           // м/с: ниже — «ТУК», без проигрыша
}
```
- **Когда сносит:** `attention ∈ {phone, drowsy, asleep, grope}` (grope — §3) после `startDelay`. В `stow`, `wake`, `earnest`, `road` не сносит. Снос одинаковый во всех уроках (решение Сергея): ни множителей, ни флага отключения.
- **Скорость:** `vLat = dir · maxLat[state] · min(1, rampFrom + tDrift/rampTime) · clamp(v/refSpeed, 0, 1.2)`. При смене состояния `drowsy → asleep` разгон не сбрасывается, меняется только потолок.
- **Направление:** первое — `sim.rng() < 0.5 ? −1 : +1`, дальше держится `holdMin…holdMax` с (по `sim.rng`), затем с вероятностью `flipChance` разворачивается. Всё на `sim.rng` — реплеи и тесты детерминированы. Добавить `sim.drift = { t, dir, holdT, vLat, active }` в `createSim`.
- **Расчёт честности** (phone, 10 м/с, вправо от 1,8 м): первый возможный удар — клумба/скамейка на ~2,4–2,5 м. 0,8 с задержки + ~3,0 с сноса ≈ 3,8 с. Asleep ≈ 3,4 с. Тест 0.5‑1 закрепляет минимум 3,0 с для любого seed.
- **Бордюр:** когда центр пересекает |x| = 2,4 м (корпус уходит с асфальта), один раз даётся тряска (4,0)/(−4,0) по 33 мс, глухой «тук» (`audio.bump()`, новый короткий звук) и пыль `steam` кадры 0–1 у колёс. Урона нет. **Спящий Антон от бордюра не просыпается** (это смешно и честно: будит только игрок). Телефонный Антон тоже не реагирует.
- **Езда по тротуару:** скорость не меняется. Пешеход или собака на бордюре (±4,15/±3,9 м) — обычная коллизия: `resolveHit`, сцена `ped`/`dog` из этапа 2, проигрыш при ≥ 1,2 м/с.
- **Удар о придорожный объект** (§0.3): при v ≥ `softHit` → `sim.lastHit = { type:"roadside", object:<name>, drift:<state> }`, `fail(sim,"body")`. `failCause` = `drift-sleep` (drowsy/asleep), `drift-phone` (phone) или `drift-grope` (grope). Сцена — `impact` вида `car` (§0.5, дописано в stage2-brief). При v < `softHit`: «ТУК», v = 0, тряска 2 шага, Антон просыпается/откладывает телефон как от финального тычка (без вздрагивания), проигрыша нет.
- **Пробуждение и возврат:** когда тычки завершают состояние (начинаются `stow`/`wake`), `vLat` гаснет до 0 за 0,25 с. Через `recoverDelay` Антон рулит обратно к `desiredX` со скоростью `recoverRate` (осторожно, медленнее обычного `steerParams`). Пока |x| > 2,4 м, кламп расширен до `maxOffset`. Как только центр вернулся за 2,4 м, кламп снова `bodyCenterLimit()`. Если машина за бордюром, при заезде обратно — ещё один «тук». Реплика по возвращении — §5.
- **Код клампа** (`sim.js` ~1100): `const lim = (sim.drift.active || Math.abs(sim.x) > bodyCenterLimit()) ? CFG.drift.maxOffset : bodyCenterLimit();`. Во время сноса `desiredX` игнорируется, `x += vLat·dt`. Обычный руль Антона никогда не просит |x| > 2,4.
- **Доверенные опасности** (`commitHazards`) не меняются: `outOfIt` расширяется до `phone || asleep || grope`. Если Антон «вне» на 40 м, он едет в опасность, а снос добавляется поверх.

## 1. Тычок в плечо: будит не сразу, бесполезный тычок злит

### 1.1 Команда
- **Геймдизайн:** телефон — 1 тычок, но он ещё 0,6 с «договаривает» (снос идёт). Дрёма — 2 тычка, сон — 3. Тычок, когда Антон в порядке, — наказание терпением, чтобы не спамили.
- **Арт:** реакция на каждый тычок (§5) и индикатор «осталось тычков» (точки под подсказкой).
- **Программист:** `pokeAttention` перестаёт быть мгновенным и получает счётчик и таймер затухания. Хотспот `anton` делится на зоны (§1.4).
- **QA:** число тычков, затухание, отсутствие штрафа во время анимаций, мультитач с педалью.
- **Мобайл:** зона плеча крупная (≥ 140 CSS px), тап срабатывает на `pointerup`, чтобы отличить его от свайпа (§3). Задержка ≤ 300 мс — допустимо, тест 1.6‑5.

### 1.2 Правила и числа (`CFG.poke`)
```
poke: {
  need: { phone: 1, drowsy: 2, asleep: 3 },
  decay: 2.5,          // с без тычка → прогресс −1
  minGap: 0.12,        // тычки чаще не считаются (дребезг)
  phoneFinish: 0.6,    // после тычка в телефон он ещё договаривает, потом stow 0,72 с
  useless: 8, uselessRepeat: 12, uselessWindow: 3.0, // штраф терпения
  bubbleCooldown: 1.2,
}
```
- `sim.poke = { count, lastT }`. Каждый засчитанный тычок: `count += 1`, реакция (§5), `stats.attentionPokes += 1`. При `count ≥ need[state]` → как сейчас `stow`/`wake`; для телефона сначала `phoneFinish` («ЩАС-ЩАС»), потом `stow`.
- Если тычка нет `decay` с — `count −1` (не ниже 0). Asleep → drowsy **не** откатывается; откатывается только счётчик.
- Переход `drowsy → asleep` по миссии **сохраняет** набранный счётчик (не обнулять — иначе нечестно).
- **Бесполезный тычок:** `attention ∈ {road, earnest}` и нет вспышки ярости → `patience += useless` (+8 ≈ 1,1 с торможения). Повтор в пределах `uselessWindow` → `+12`. Реплика «ДА ЕДУ Я!» (повтор: «ДА ЕДУ Я, ЕДУ!»), поза `grumble` 0,8 с. Счётчик `stats.uselessPokes`. Терпение влияет на звёзды через `grade()` (mood) — отдельной механики не нужно. Если терпение доходит до 100 — обычная вспышка «НУ ВСЁ!».
- **Без штрафа:** во время `stow`, `wake`, `phoneFinish`, `grope`, вспышки, `countdown`, `impact`, `result`, паузы. Там тычки игнорируются.
- Подсказка `CALLOUT` (draw.js ~384) остаётся, только текстом. Точек прогресса нет (§A.3).

### 1.3 Код
- `config.js`: `poke`.
- `sim.js`: `pokeAttention(sim)` → `registerPoke(sim)` с правилами выше. Возвращает `{counted, done, useless, flinch}` для звука и вибрации. Старое имя оставить обёрткой (тесты, реплеи).
- `session.js`: очередь тычков `tapQueued` → массив событий `{kind:"poke"|"swipe"|"honk", t}`, обрабатывается в шаге симуляции (детерминированно в реплее, если реплей пишет ввод).
- `game.js`: звук тычка (короткий «тык», новый `audio.poke()`), `haptics` при бесполезном тычке.
- `draw.js`/`cabin.js`: позы по §5, точки прогресса.

### 1.6 Тесты
Юнит: 1) phone: 1 тычок → 0,6 с снос продолжается → `stow` → `earnest`. 2) asleep: 2 тычка — ещё спит; 3‑й → `wake`. drowsy: 2. 3) затухание: тычок, пауза 2,6 с → `count` уменьшился. 4) бесполезный тычок в `road`: `patience +8`, повтор через 1 с `+12`, реплика «ДА ЕДУ Я!»; в `stow`/`wake` — 0 штрафа. 5) `drowsy→asleep` сохраняет `count`.

### 1.7 Риски
- Тап на `pointerup` вместо `pointerdown` чуть «мягче». Если Сергею не понравится, вариант: засчитывать на `pointerdown`, а свайп определять только в зоне `phone`.
- Штраф +8 может оказаться слишком строгим для детей/новичков — подобрать по тесту с Сергеем.

## 2. Риск тайминга: тычок в опасный момент — Антон вздрагивает и дёргает руль

### 2.1 Команда
- **Геймдизайн:** будить надо заранее, а не перед самой опасностью. Это решение игрока, а не случайность: правило полностью предсказуемо.
- **Арт:** поза вздрагивания влево/вправо (§5), реплика.
- **Программист:** боковой импульс поверх `desiredX`, может выйти за 2,4 м и задеть обочину/хазард по обычным правилам.
- **QA:** нет вздрагивания вне окна опасности; направление детерминировано.

### 2.2 Правила (`CFG.flinch`)
- **Опасный момент** = ближайший нерешённый хазард впереди, `0 < dist ≤ warnMetres(cruise)` (то самое окно «!»), **или** пешеход/собака в движении (`enter/linger/dart`) в пределах 20 м.
- **Кто вздрагивает:** тычок, завершающий пробуждение из `asleep` (0,6 м), из `drowsy` (0,4 м); тычок в телефон (0,3 м); бесполезный тычок (0,3 м) и гудок, разбудивший спящего (как финальный тычок: 0,6 м из сна, 0,4 м из дрёмы). Промежуточные тычки сна (1‑й, 2‑й) не вздрагивают — он только ворочается.
- **Форма импульса:** смещение `A` к `x` за 0,20 с (smooth), держится 0,15 с, возврат 0,60 с. Итого 0,95 с. Суммируется с текущим рулём/возвратом. Кламп — расширенный (`maxOffset`), как при сносе.
- **Направление:** от хазарда: `dir = −sign(hazardWorldX − x)`; если |разница| < 0,3 м — `sim.rng()`. Значит, вздрагивание часто уводит **на обочину** (вправо из полосы 1,8 м) — опасно, как и задумано.
- **Последствия:** обычные — бордюр, удар о скамейку/клумбу (`failCause = "flinch"`, подпись в §2.4), хазард → его сцена.
- Реплика: «А?! ЧТО?!» (сон), «НЕ ПУГАЙ!» (бесполезный/телефон). Звук — короткий визг шин `audio.squeal()` (новый, короткий).

### 2.3 Код
- `config.js` `flinch: { asleep:0.6, drowsy:0.4, phone:0.3, useless:0.3, up:0.2, hold:0.15, back:0.6, pedDanger:20 }`.
- `sim.js`: `inDanger(sim)`; в `registerPoke` → `startFlinch(sim, amp)`; `sim.flinch = {t, dir, amp}`; в шаге `x += flinchOffsetDelta`.
- `getState()`: `flinch: sim.flinch ? {dir, amp, t} : null`.

### 2.4 Подпись на карточке
`flinch` → «Антон дёрнулся. / Буди заранее.» (утверждено.)

### 2.5 Тесты
Юнит: 1) Будим на 3‑м тычке при dist = 50 м до ямы → вздрагивания нет. 2) То же при dist ≤ `warnMetres` → `flinch.amp = 0.6`, направление от ямы. 3) Импульс возвращается к нулю за 0,95 с. 4) Промежуточный тычок сна в опасности — без вздрагивания. 5) Вздрагивание у клумбы (подобранный seed/миссия) → `failCause = "flinch"`.
E2E: `debugFlinch()` визуально — поза вздрагивания и смещение машины (скриншот).

### 2.6 Риски
- Двойная кара (спит у опасности + вздрогнул) может казаться нечестной. Компромисс: амплитуда 0,6 м не достаёт до скамейки из 1,8 м (2,4 < 2,5), но достаёт до клумбы (2,40). То есть вздрагивание опасно, но не всегда смертельно. Подобрать с Сергеем.

## 3. Смахнуть телефон: падает на коврик, Антон шарит по полу

### 3.1 Команда
- **Геймдизайн:** быстрый и смешной, но рискованный выбор. Телефон сразу убран от уха, но Антон 2 с «вне» и сносит **сильнее**, чем с телефоном. Ценность: телефон конфискован до конца поездки (если в миссии будут повторные звонки — их не будет), плюс шутка. Тычок во время поисков возвращает Антона быстрее.
- **Арт:** падение телефона и поиски — это **позы Антона** (фон кабины не меняется, коврик не виден — он под панелью; телефон «улетает» за панель в кадрах позы).
- **Программист:** жест свайпа, новое состояние `drop → grope → surface`.
- **QA:** жест не мешает педали, не путается с тапом; клавиша G.
- **Мобайл:** только горизонтальный свайп (вертикальный в Telegram может закрыть браузер). Альтернатива для доступности — долгое нажатие 0,6 с на телефоне.

### 3.2 Правила (`CFG.swipe`)
- **Жест:** `pointerdown` в зоне `phone` (активна только в `attention === "phone"`), затем смещение |dx| ≥ 64 канвас-px (~30 CSS px) при |dx| > 1,5·|dy| в течение 400 мс → свайп. Долгое нажатие ≥ 600 мс без движения — тоже свайп. Короткий тап в этой зоне = обычный тычок §1.
- **Состояния:** `drop` 0,45 с (кадры полёта телефона, реплика «ЭЙ!») → `grope` 2,0 с (Антон нагнулся, шарит, «ГДЕ ОН…», снос `maxLat.grope = 0.45`) → `surface` 0,4 с («НАШЁЛ!» — кладёт телефон в карман) → `earnest`. `sim.phoneConfiscated = true`, `phonePlayed = true`.
- Тычок во время `grope` → сразу `surface` с репликой «ЛАДНО, ПОТОМ…» (телефон остался на полу). Без штрафа терпения.
- `grope` входит в `outOfIt` (доверенные опасности на 40 м он «не видит»), снос продолжается без сброса разгона (непрерывно от телефонного).
- Вздрагивание: свайп в опасный момент → амплитуда 0,3 м (как тычок в телефон).
- Удар во время `grope` → `failCause = "drift-grope"`.
- Звук: «бряк» телефона о пол `audio.thud()` (новый).

### 3.3 Код
- `config.js` `swipe: { minDx:64, ratio:1.5, maxMs:400, longPress:600, drop:0.45, grope:2.0, surface:0.4 }`.
- `session.js`: `pointerMove` для `wakeId`, распознавание свайпа/долгого нажатия; событие `{kind:"swipe"}`; KeyG.
- `sim.js`: `swipePhone(sim)`, `advanceAttention` с новыми состояниями, `outOfIt`.
- `physics.js expressionId`: новые состояния возвращаются как есть. `pixel-world.js PIXEL_POSE`: `drop`, `grope`, `surface` и кадры из `assets/pixel/taps/cabin/` (временных поз нет, §A.4).
- `draw.js` / `pixel-world.js drawPixelCabin`: подсказка в телефонном состоянии — **«Ткни или смахни телефон»** (утверждено). Для сна остаётся «Разбуди — ткни в Антона».

### 3.4 Тесты
Юнит: 1) свайп → `drop` 0,45 → `grope` 2,0 → `surface` 0,4 → `earnest`, `phoneConfiscated`. 2) тычок в `grope` → `surface` сразу. 3) снос в `grope` быстрее, чем в `phone`, разгон непрерывен. 4) `outOfIt` в `grope`. 5) повторный `phoneAt` в той же поездке не срабатывает.
E2E: 1) touch-свайп по зоне телефона (CDP: down → 6 move по 14 px → up за 200 мс) → `attention === "drop"`. 2) Свайп с удержанной педалью вторым пальцем → педаль не отпущена. 3) Вертикальный свайп — не свайп, а тычок. 4) Долгое нажатие 700 мс → свайп. 5) KeyG.

### 3.5 Риски
- Распознавание на `pointerup` для тапа + свайп на `pointermove` — проверить на реальном iPhone (Сергей), Playwright это не гарантирует.
- Обнаружение свайпа — только текстом подсказки; стрелок и значков нет (решение Сергея).

## 4. Гудок: тап по рулю

### 4.1 Команда
- **Геймдизайн:** инструмент против «живых» опасностей: пешеход отскакивает, собака убегает. На неодушевлённое не действует никак. Чтобы не стать кнопкой «пройти урок», у гудка есть кулдаун, цена в терпении и правило «у зебры гудеть — грубо».
- **Арт:** «БИП!» у носа машины, звуковые дуги, кадры отскока пешехода и бега собаки. Индикации кулдауна на руле нет (решение Сергея).
- **Программист:** зона `wheel`, реакции акторов на событие гудка.
- **QA:** статика не двигается, кулдаун, нет пересечения со счётчиком вспышек `stats.honks`.
- **Мобайл:** зона руля 121×48 CSS px, буфер до педали 60 CSS px.

### 4.2 Правила (`CFG.honk`)
- Кулдаун **5 с** (утверждено). Во время кулдауна тап по рулю ничего не делает, только тихий «клик». **Никакой индикации на руле** (без значков поверх кабины).
- Цена: `patience += 4` («ТЫ ЧЕГО СИГНАЛИШЬ?» на первый гудок за поездку, дальше без реплики). Счётчик **`stats.playerHonks`**, а не `stats.honks`: тот считает вспышки Антона, и на нём висит `audio.honk()` в game.js. Звук игрока — тот же `audio.honk()`, вызывается напрямую.
- Радиус: хазарды впереди, `0 < dist ≤ 30 м`. Реакции:

| Кто / в каком состоянии | Реакция |
|---|---|
| пешеход `curb` (ещё ждёт) | вздрагивает (`alarm`), остаётся на бордюре, пока машина не проедет; кулак (`fist`) |
| пешеход `enter` при dist ≥ 12 м | отскок обратно на бордюр за 0,35 с (`hopback`), ждёт, пока машина проедет |
| пешеход `linger/leave` или dist < 12 м | ускоряется ×1,8 к ближайшей стороне, без отскока; от наезда при малой дистанции **не спасает** |
| собака `curb`/`dart` | убегает от дороги за 0,6 с (`flee`, бег ×1,6) и исчезает за бордюром (`off`) |
| NPC-выезд (`cutin`) в `curb`/ранний `enter` | водитель NPC ждёт (`yielded = true`), машина остаётся у бордюра |
| припаркованная машина, бак, крышка, яма, дома, предметы | **ничего** (неодушевлённое не двигается) |

- Хазард, убранный гудком, отмечается `markClear(sim, h, "honk")`. Это считается разрешённой опасностью: доверие/«earnest» снимаются как обычно.
- **Зебра:** гудок по пешеходу, который уже на переходе или подходит к нему (`enter/linger`), — грубость: `stats.rudeHonks += 1`, у пешехода кулак и `anger`. Дефолт реализации: `rudeHonks > 0` снимает значок `badge` в `grade()`, звёзды не трогает.
- **Гудок будит Антона** (решение Сергея): в `drowsy`/`asleep` гудок сразу завершает пробуждение, как последний тычок (`wake` → «ИЗВИНИ!»), независимо от набранных тычков. Правило вздрагивания §2 действует: в опасный момент — рывок 0,6 м (сон) / 0,4 м (дрёма). На телефон и поиски гудок не влияет (Антон не спит). Цена гудка та же: +4, кулдаун 5 с.

### 4.3 Код
- `config.js` `honk: { cooldown:5, radius:30, hopMin:12, cost:4, hurry:1.8, dogFlee:0.6 }`.
- `layout.js`: `WHEEL_ZONE`; `draw.js`: хотспот `wheel`.
- `session.js`: `honkId`, событие `{kind:"honk"}`, KeyH.
- `sim.js`: `playerHonk(sim)` → `sim.honkCdT`, проход по хазардам, новые `motion`: `hopback`, `wait` (пешеход), `flee` (собака); `advancePedestrian/Animal` их обрабатывают; `actorTravel` для анимации шагов.
- `pixel-world.js`/`cast.js`: кадры `hopback` (reuse `ped-*-react` 0–2 из этапа 2), `flee` (новый бег собаки), `БИП!`, дуги.
- `game.js`: `audio.honk()` при `playerHonks` ↑, `getState().honk = { cd, playerHonks, rudeHonks }`.

### 4.4 Тесты
Юнит: 1) Пешеход `curb` на 25 м + гудок → не выходит на дорогу, машина проезжает без торможения, без проигрыша. 2) Пешеход `linger` на 8 м + гудок → ускорился, но без торможения — наезд (сцена `ped`). 3) Собака на 15 м → `flee` → `off`, без проигрыша. 4) Кулдаун: два гудка через 1 с — второй без эффекта; через 5,1 с — работает. 5) **Ни один статичный/припаркованный хазард и ни один придорожный объект** не меняет `pose` после гудка. 6) `stats.honks` (вспышки) не растёт от гудка игрока; `playerHonks` растёт; `patience +4`. 7) Гудок по пешеходу на зебре → `rudeHonks = 1`.
E2E: 1) тап по рулю (touch) при удержанной педали → `playerHonks = 1`, `brakeHeld === true`. 2) KeyH дважды за 1 с → `playerHonks = 1`. 3) Гудок будит спящего: `attention` → `wake` с первого гудка; у опасности — `flinch.amp = 0.6`.

### 4.5 Риски
- Баланс: гудок может обесценить уроки с пешеходами. Поэтому кулдаун 5 с, +4 терпения, окно ≥ 12 м и грубость на зебре.
