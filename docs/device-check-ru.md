# Проверка на живом телефоне

Это список для Сергея. Агент его не проходил: ни iPhone Safari, ни Android Chrome в руках не были. Headless WebKit и эмуляция 844×390 — не телефон.

Игра: альбом, 16:9. В портрете должен быть только просьба повернуть экран. Игрок только тормозит.

## iPhone, Safari

- [ ] Открыть собранную страницу с `main` после отдельного разрешения на публикацию. Ветка разработки сайт не обновляет.
- [ ] Повернуть в альбом. Холст целиком, без обрезки педали и без залезания на чёлку и домашний индикатор.
- [ ] Адресная строка спряталась и снова выехала. Картинка не прыгает на пиксель и не меняет размер.
- [ ] Один палец на педали: короткое нажатие притормаживает, долгое останавливает. Палец можно увести с кнопки, тормоз держится, пока палец на экране.
- [ ] Второй палец по Антону, пока первый держит тормоз. Тормоз не отпускается. Тычок будит или убирает телефон, педаль — нет.
- [ ] Отпустить палец, сработать `touchcancel` (шторка, звонок). Педаль отпускается.
- [ ] Свернуть Safari и вернуться. Игра на паузе, тормоз сброшен.
- [ ] Вибрация: одно короткое при нажатии, чуть длиннее на резкий тормоз, не гудит всё время удержания. Выключатель в настройках её глушит. Если iOS не отдаёт `navigator.vibrate`, это нормально — отметить «нет API», не чинить молча.
- [ ] Звук после первого касания. Выключатели эффектов, музыки и голоса работают по отдельности.
- [ ] «Меньше движения» убирает дрожание. «Крупный текст» не обрезает кнопки.
- [ ] Повтор с итога — один тап, без 3–2–1.
- [ ] Глазами: машина не трапеция, руки Антона на руле, фон салона не прыгает при смене позы.

## Android, Chrome

- [ ] То же альбомное кадрирование и безопасные поля.
- [ ] Два пальца: тормоз и тычок в Антона, оба порядка.
- [ ] Уход приложения в фон и назад: пауза и сброс педали.
- [ ] Вибрация есть и выключается. Импульс короткий, не непрерывный.
- [ ] Поворот экрана туда-сюда не оставляет портретную вёрстку и не залипает педаль.
- [ ] На слабом телефоне кадр не рассыпается. Ориентир из эмуляции — единицы миллисекунд на кадр при буфере 1600×900; на устройстве замерить отдельно и записать число сюда.

## Что записать в ответ

Модель, iOS/Android, Safari/Chrome, держится ли тормоз вторым пальцем, есть ли вибрация, прыгает ли кадр при адресной строке, и одно предложение: смешно ли тормозить.
