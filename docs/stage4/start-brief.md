## Жёсткие правила

- Только целый ×4, без сглаживания (`imageSmoothingEnabled = false`), только цвета пака.
- Ничего не перерисовывать и не масштабировать. Каждый PNG из `assets/pixel/start/` ставится как есть, в координаты из `start-layout.json` ×4.

- Коммиты: `-c user.name="Sergey Duvakin" -c user.email="sergeyduvakin@users.noreply.github.com"`.
- Не утверждать, что игра проверена на физическом iPhone. Мобайл здесь — Playwright 896×414.

## 3. Живая улица (attract mode)

Улица в макете **горизонтальная**. Обычный `drawPixelWorld` рисует вертикальную дорогу, поэтому его целиком не переиспользовать. Переиспользовать нужно его части:
- `pixelImage`;
- блит спрайта ×4 из `pixel-world.js`;
- тени из манифеста (`shadow`);
- кадры актёров из `manifest.sprites`.

Новая функция — `drawPixelAttract(ctx, state)` в `js/pixel-start.js` (новый модуль).

Статичная сцена, координаты из `start-layout.json → scene`:
- дом `block-teal-tall`, 6 деревьев, 2 лавки, клумба;
- светофор (зелёный), знак зебры, гидрант, урна, люк.

Всё это **не двигается никогда**.

Актёры (только они двигаются). В эталоне — позы кадра 0.
- **Учебная машина** `learner-normal-right` (112,137) стоит на месте, мотор на холостых. `exhaust-0` мигает: 400 мс показан, 400 мс нет. Второго кадра выхлопа нет (см. §11), поэтому так.
- **NPC** `npc-white-left` едет по верхней полосе справа налево. Скорость 24 нат. px/с, x — целые. Уехал за x < −44 → пауза 4–9 с → снова с x = 400. Изредка вместо белой `npc-blue-left`. Нижнюю полосу не занимать: там стоит машина Антона.
- **Пешеход** `ped-pink-right-0/1`: верхний тротуар, вправо, 8 нат. px/с, смена кадра каждые 250 мс. Ушёл за край → пауза → снова слева. Перед зеброй дорогу **не переходит** (на старте нет опасностей).
- **Пешеход** `ped-blue-left-0/1`: нижний тротуар, влево, так же.
- **Собака** `dog-right`/`dog-left`: на нижнем тротуаре делает 1–2 коротких перебежки по 12 px, потом стоит 3–6 с. Готовых беговых кадров для старта нет, используется статичный спрайт со сдвигом по целым px.
- **Антон**: поза `yasam`. Готовых кадров моргания для старта нет, поза статична. Пузырь «ПОЕХАЛИ?» постоянный.

Порядок по y: все спрайты сцены и актёры сортируются по нижней кромке (как сейчас в мире), иначе пешеход окажется «под» лавкой.

Случайность — детерминированная (seed, как в мире), чтобы e2e-тест мог её остановить. Нужен `window.__anton.attractFreeze(true)`: замораживает все таймеры и ставит актёров в позиции эталона. При заморозке кадр должен совпасть с эталоном (§9).

Тени: в эталоне у спрайтов **нет теней**. По умолчанию рисовать без теней, как утверждено. Добавлять тени мира — только если Сергей скажет (§11).

Опасностей на старте нет. Сессия (`session`) не создаётся, пока не нажата ПОЕХАЛИ!.

## 4. Полоса загрузки — настоящий прелоад

Сейчас `boot()` ждёт `whenCarsReady` → `whenCabinReady` → `whenPixelReady` и только потом запускает `requestAnimationFrame`. До этого экран пустой.

Нужно так:
1. **Фаза 0 (мгновенная).** Сначала загрузить только группу `start` (≈ 8 КБ на все `start/*.png`), шрифт и спрайты сцены. Сразу начать рисовать стартовый экран с пустой полосой.
2. **Фаза 1.** Остальной прелоад. Добавить в `whenPixelReady(onProgress)` колбэк `onProgress(done, total)`, где `total` — реальное число ожидаемых файлов. В него входят:
   - все PNG из `collectPngs(manifest)`;
   - шрифт;
   - файлы `whenCarsReady` и `whenCabinReady`.
   
   Число `N` вычисляется, а не пишется руками: в макете стоит 91, сейчас в манифесте 104 PNG + новые.
3. **Полоса.** 36 слотов: x = 42 + 5·i, i = 0…35. Последний слот шириной 2 px (x 217–218). Залито `floor(36 · done / total)` слотов. Слот = `loadbar-segment.png`, для последнего — crop 2×7.
4. **Подпись.** Собирается из `font9-ink.png` по `font9-ink.json`, так не зависит от того, загрузился ли TTF (это требование 4.3). Ширина `lw` — сумма `adv`. Расположение:
   - x = 40 + ⌊(180 − lw)/2⌋;
   - глиф рисуется в (pen, y − 1), где y = 211 + ⌊(11 − 7)/2⌋ − 2 = 211;
   - для эталона `l0 = 2, l1 = 9`; проверить: подпись «ГОТОВО · 91/91» должна совпасть с `loadbar-label-ref.png`;
   - кремовая подложка: x от (40 + ⌊(180 − lw)/2⌋ − 3) до (40 + ⌊(180 + lw)/2⌋ + 2), y от 212 до 220.
5. **Тексты.**
   - Во время загрузки: «ГРУЗИМ ДВОР · n/N» (из чек-листа 4.2, ждёт подтверждения, §11).
   - Готово: «ГОТОВО · N/N» (утверждено).
   - Ошибка (4.3): «НЕ ЗАГРУЗИЛОСЬ · ЕЩЁ РАЗ», тап по полосе = повтор только упавших файлов, до 3 раз. Красный цвет полосы — нового арта нет, спросить (§11).
6. **Кнопка ПОЕХАЛИ! и чипы** рисуются и активны только после «ГОТОВО». До этого на их месте трава (ground).
7. **Классика.** Если пиксельный пак так и не загрузился (3 попытки), экран уходит в классику, как сейчас (`usePixel` = false → старый `drawTitle`).

## 5. Кнопки

Решение по ПОЕХАЛИ!, из текущего кода. Сейчас `activate("start")` всегда запускает `startMission("lesson1")` (`game.js:188`). Сохранение (`storage.js`) хранит:
- `unlocked` — 1…4, наибольший открытый урок;
- `best[lessonN]` — звёзды пройденных уроков.

Правило — новая чистая функция `startLesson(save)` в `ui.js`:
- первый по порядку `lesson1…lesson4`, у которого `lesson ≤ unlocked` и нет `best[id]`, — то есть следующий открытый и ещё не пройденный;
- если все открытые пройдены — `lesson${unlocked}` (последний открытый);
- свежий профиль → `lesson1`.

`activate("start")` → `startMission(startLesson(save))` (через `canPlay`). Enter и Space на титуле делают то же (`game.js:479`).

Первый тап по ПОЕХАЛИ! (чек-лист 4.2):
- `audio.unlock()` + короткий гудок;
- затем отсчёт 3-2-1-ПОЕХАЛИ! — текстом из атласа, нового арта нет;
- опасности — только после «ПОЕХАЛИ!».

Пункт 4.2 «тап в любом месте стартует» ограничить: тап вне хитбоксов ГАРАЖ и ЗВУК = ПОЕХАЛИ!, только после «ГОТОВО».

- **ГАРАЖ** → существующий `activate("garage")`, без изменений.
- **ЗВУК** → существующий `toggle("sound")`. Он уже сохраняет `save.settings.sound` в localStorage через `persist()` и применяет `audio.setEffects`. Музыка и голос остаются отдельными настройками в гараже.

  Состояние «выключено» нарисовать нечем: в утверждённом макете только включённый чип (§11). До утверждения арта чип ЗВУК всегда выглядит одинаково, а `aria-label` / метка `labels` говорит «Звук: вкл/выкл».

## 7. Безопасные зоны: Telegram Mini App и Safari

- **Safari / iOS.** Уже работает: `#wrap` имеет `padding: env(safe-area-inset-*)` (`style.css` строки 42–45, 71–74, 117–120), а `frameSize` вписывает 16:9 внутрь. На iPhone 11 вся раскладка, включая полосу (низ на 386 из 393 CSS px), — внутри безопасной зоны, над полоской «домой». Ничего к краю экрана не прижимать.
- **Telegram Mini App.** SDK в репо нет. Подключить `https://telegram.org/js/telegram-web-app.js` только если `window.Telegram?.WebApp` существует или открыто внутри Telegram; без него ничего не ломать. В Telegram:
  - вызвать `Telegram.WebApp.ready()` и `expand()`;
  - отступ = `safeAreaInset` + `contentSafeAreaInset` (Bot API 8.0+, события `safeAreaChanged` / `contentSafeAreaChanged`; CSS-переменные `--tg-safe-area-inset-*` и `--tg-content-safe-area-inset-*`);
  - padding `#wrap` = max(env(...), tg-инсет) по каждой стороне;
  - после события — `dispatchEvent(new Event("resize"))`.
  
  Кнопки Telegram (Close/⋯ сверху) попадают в `contentSafeAreaInset.top` — лого не должно уходить под них.
- Портрет: существующий экран «поверни телефон» остаётся. Его пиксельная версия — отдельный пункт 4.2, нового арта нет.

9. **Неживое.** Два кадра attract через 2 с: пиксели статичных спрайтов (маска по bbox из `scene`, кроме мест, где их перекрыл актёр) не изменились.

## 11. Неясно — спросить Сергея до кода

1. **Выхлоп.** В макете один кадр (6 пикселей); в коде макета написано «два кадра чередуются», но второго нет. Предложение: мигание одного кадра (§3) или нарисовать второй кадр на утверждение.
2. **ЗВУК выключен.** Арта состояния «выкл» нет (зачёркнутый динамик). Нужен на утверждение.
3. **Горизонтальная улица.** Мировой рендер вертикальный. Сцена собирается из тех же спрайтов, но отдельной функцией. Тени спрайтов в эталоне отсутствуют; сейчас без теней.
4. **Подпись загрузки.** В макете «ГОТОВО · 91/91»; на время загрузки предлагается «ГРУЗИМ ДВОР · n/N» (чек-лист 4.2). 91 в макете — устаревшее число; в игре будет реальное N.
5. **Красная полоса ошибки** (4.3) — нового арта нет.
6. **Движение актёров.** Готовых беговых кадров собаки для старта и моргания Антона в позе `yasam` нет. Чек-лист 4.2 упоминает «Антон моргает/палец» — нужен кадр на утверждение, иначе поза статична.
7. **Углы элементов.** Угловые пиксели кнопки и чипов закрашены цветом травы `5CB87A`, а пузыря — цветом окна кабины `A6D1E4` (так в макете, экспорт точный). На крапе травы это заметно не будет. Если Сергей захочет, сделать их прозрачными — это изменение арта.
8. **Последний слот полосы** — 2 px вместо 4 (так в макете).
